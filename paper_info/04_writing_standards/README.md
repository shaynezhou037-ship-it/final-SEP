# 论文写作标准库

本目录只保存跨阶段反复使用的标准，不保存正文版本、实验数据或论文 PDF。

当前有效文件：

- `IEEE_HIGH_QUALITY_PAPER_BENCHMARK.md`：基于已全文阅读论文和 IEEE 官方页面形成的写作/图表基准；
- `LANGUAGE_AND_CLAIM_AUDIT_STANDARD.md`：英文、主张、数字、引用和图表文字的逐句审计规则；
- `AI_ASSISTED_WRITING_AND_DISCLOSURE_RULES.md`：AI 辅助边界、IEEE 披露要求和作者终审规则；
- `AI_USE_LOG.csv`：从现在开始记录生成式 AI 的实际用途，投稿前据此写 Acknowledgment。

规则：标准文件在原文件上更新；除非审计逻辑发生根本变化，不创建 `v2/v3/final_final` 副本。
